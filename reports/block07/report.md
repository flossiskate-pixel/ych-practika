# Блок 7. Сравнение IDE
В ходе работы сравнивались VS Code, Visual Studio и Eclipse (PyDev).
- VS Code: Быстрый запуск, легковесный, идеален для Python. Использовался как основная среда.
- Visual Studio: Тяжелее, но имеет мощный отладчик и компонент Python Development.
- Eclipse (PyDev): Устаревший интерфейс, требует долгой настройки. Для данного проекта подходит меньше всего.
Вывод: для веб-разработки на Flask оптимален VS Code.
